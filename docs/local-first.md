# Local-First Policy

Real-Time Local Translator is designed to operate without paid services or cloud APIs.

## Runtime

Audio capture, voice activity detection, speech recognition and translation run on the local computer using installed open-source components and local model files.

## Internet

Internet access may be used during development or initial model/package installation. The running application must not require an external API, account, subscription, API key, usage credits or per-minute billing.

## Privacy

Meeting audio and transcripts are not uploaded by the application. Diagnostic recordings are development-only and must never be committed to the repository.

## Dependencies

Every runtime dependency must be reviewed for license, offline operation, Windows compatibility, packaging feasibility and maintenance before becoming part of a release.
